# 高频量化终端主题设计

日期：2026-09-10

## 目标

将 Exchange Data 的视觉语言调整为专业的高频加密货币量化终端，并把原暗色主题改为克制的黑客终端风格。页面结构、交互流程、信息密度和业务行为保持不变。

## 视觉系统

浅色主题使用冷白工作区、白色面板、深海军蓝文字、电光青蓝主色。颜色强调数据、状态和操作层级，不使用装饰性渐变作为大面积背景。核心色值：

- 工作区 `#F2F6F8`，面板 `#FFFFFF`，柔和面板 `#EAF1F4`。
- 正文 `#0A1929`，次要文字 `#536879`，边线 `#CBD8DF`。
- 主色 `#007F8B`，辅助蓝 `#1769E0`。
- 上涨/成功 `#008F68`，下跌/错误 `#D33F55`，警告 `#B56A00`。

暗色主题使用近黑绿色底、分层墨绿面板、荧光青绿主色和冷青辅助色。背景加入低对比度细网格，交互元素使用有限辉光；正文和表格保持足够对比度，不使用持续动画、闪烁或高饱和大面积填充。核心色值：

- 工作区 `#020806`，面板 `#07110D`，柔和面板 `#0A1712`。
- 正文 `#D7FBE8`，次要文字 `#78A892`，边线 `#173C2D`。
- 主色 `#39FF9A`，辅助青 `#22D3EE`。
- 上涨/成功 `#39FF9A`，下跌/错误 `#FF5678`，警告 `#F7C65A`。

暗色主题的标题、状态栏、活动页签、按钮和锚点行可以有轻微荧光边缘。表格数字继续使用等宽字体，网格和斑马纹保持低对比度，避免影响长时间监看。

## 图标

Web favicon 使用单字“鲸”作为 Logo。图标为深色圆角方形底，文字使用青绿色，视觉上与暗色终端主色一致。SVG 通过 Dioxus `asset!` 管理，并由 `document::Link` 写入页面 `<head>`，随 Web 资源嵌入 Axum 二进制。

## 验收

- 浅色与暗色主题都能正常切换，所有文字、表单、表格和状态标记清晰可读。
- 暗色主题呈现黑客终端气质，但没有闪烁、强动画和大面积纯荧光色。
- 构建后的 `index.html` 引用哈希化 favicon，静态资源目录包含 SVG。
- Web WASM 检查、Dioxus Web bundle 和 Ubuntu x86_64 交叉编译成功。
- 在桌面宽度下进行浏览器截图检查，并确认现有移动断点没有被主题样式覆盖。
