# Exchange Data 本地性能记录

日期：2026-09-09。构建：release，Rust 1.98.0、Dioxus / dx 0.7.10；Web 关闭调试符号并经过 wasm-opt。

Web DOM / 并发样本对应 UI 提交 `973b605`，采集于 h2 补丁更新之前；h2 更新后通过 26 项相关回归。下述包体与桌面启动数据已在包含 `h2 0.4.16` 的最终包重新核对。

环境：macOS 26.6.2（25G83），Intel Core i9-9880H 2.30 GHz，64 GiB RAM；浏览器为 ego-browser 的 Chromium 150，1776 × 908 视口；Desktop 使用系统 WKWebView。所有网络请求指向同机 Rust fixture，未使用真实 Binance 网络或 Key。测试期间机器还运行了构建及审查任务，样本较少，不作吞吐或 p95 承诺。

## 下载与构建体积

- Web 发布目录总计 1,758,085 字节（约 1.68 MiB），含 index、JS、WASM 和两份 CSS；这是未压缩文件体积，不含 HTTP 头，未将缓存命中计为首次下载。
- WASM 1,694,987 字节；JS 48,177 字节；CSS 合计 14,393 字节。
- 内嵌 Web 的 macOS 服务二进制 14,599,384 字节（约 13.9 MiB）。
- macOS `.app` 文件总计 14,759,248 字节（约 14.1 MiB），不含系统 WKWebView。

构建脚本清理该应用的生成资源 staging，避免旧哈希资源混入包体。Windows 包体尚未测量。

## 本机并发保护

5 轮，每轮同时提交 8 个 USD-M 1,000 条查询，共 40 次。服务默认并发额度为 4：

- 每轮 4 个 HTTP 200、4 个 HTTP 429；总计各 20 次。
- 成功请求总耗时 5.15–10.74 ms；超额拒绝 1.71–3.91 ms。
- 每个完整成功窗口为两次上游 historicalTrades 请求。

这里的 429 来自本地并发保护，不是 Binance 的 IP 权重限流。真实上游的延迟、权重额度和网络故障需另行测量。
